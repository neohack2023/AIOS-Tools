# Cartography Slice 4

## Scope

This bounded slice adds:

- one real read-only Google Drive ancestor-chain adapter
- source-backed Drive Graph IR snapshot assembly
- exact registered Notion↔Drive identity resolution
- deterministic cross-source drift comparison
- reproducible source evidence and negative tests

## Authority

- Notion remains authoritative.
- Google Drive remains `DRIVE_SHADOW`.
- GitHub owns executable implementation truth.
- Cross-source identities require explicit evidence-backed bindings.
- Labels, paths, filenames, and semantic similarity never create identity.
- Drift reports describe differences; they do not reconcile or write sources.

## Excluded

- source mutation
- automatic conflict resolution
- fuzzy or label-only matching
- renderer and layout worker
- third live adapter
- capability activation
- Active promotion
