# Authority Boundaries

## Notion

Authoritative for AIOS architecture, governance, approved contracts, specifications, and migrated durable project memory until governed cutover.

## Google Drive

Owns registered runtime/control-plane shadows, evidence packages, source artifacts, implementation packages, and execution receipts according to declared authority. Placement alone does not promote authority.

## AIOS-Tools GitHub repository

Authoritative for live source code, repository configuration, tool registry versions, executable policies, tests, adapters, commits, branches, pull requests, and CI outcomes.

## Non-transfer rule

Execution produces evidence. Tests prove behavior under tested conditions. Neither execution nor a passing check may silently revise architecture, governance, or durable memory. Such changes return through STONE → MASON and the appropriate authoritative surface.
